# Shoot Space AI

Shoot Space AI is a free, self-hosted fashion image studio for Windows, macOS,
and Linux. Each user runs the browser interface and AI generation privately on
their own computer.

Download the current installer from the latest release. Installed copies check
`latest.json` when they start, verify the SHA-256 checksum, and apply app updates
while preserving local AI models, runtime files, and generated images.
